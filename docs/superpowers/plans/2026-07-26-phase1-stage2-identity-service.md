# Phase 1 — Stage 2: Identity Service — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `apps/identity-service` (NestJS) — user registration/login/JWT auth, organizations with roles, API keys, and a shared Auth Guard — so every later Phase 1 service can answer "who is this, and are they allowed to do this?" per the EDD's internal build order (Section 11: Auth → Organizations → API Keys → Auth Guard).

**Architecture:** A single NestJS app (`apps/identity-service`) talking to the existing `@rivocloud/db` (Prisma/PostgreSQL) and a new Redis connection (refresh tokens, JWT blacklist). JWT access tokens are RS256-signed and self-verifying (no DB hit); refresh tokens are opaque, single-use, rotated, and stored hashed in Redis, mirroring the API-key lookup-then-hash-compare pattern. One shared `AuthGuard` recognizes both `Authorization: Bearer <jwt>` and `X-API-Key: rc_...` and normalizes both into `request.auth`. Two internal, secret-header-protected endpoints (`/internal/auth/verify-token`, `/internal/auth/verify-api-key`) let future services (CDN, Storage, ...) verify credentials without importing this app's code.

**Tech Stack:** NestJS 10 (Express platform), `@nestjs/jwt`, `class-validator`/`class-transformer`, `bcryptjs` (pure-JS — see deviation below), `ioredis`, `nats` (JetStream client), `bs58`, `tsx` (dev)/`tsc` (build), Vitest + Supertest (matches repo test-runner convention from `packages/config`/`packages/db`).

## Global Constraints

- Every API is versioned from day one: all public endpoints under `/api/v1/...` (per PRD Section 6, EDD Section 7). Internal endpoints are under `/internal/...`, unversioned, per EDD Section 7.9.
- Passwords, API keys, and password-reset/email-verification tokens are never stored raw — only hashed (per EDD Section 8.1, concept doc Section 2). Deviation: use `bcryptjs` (pure JS) instead of native `bcrypt` — this is a Windows dev machine without guaranteed node-gyp build tools, and `bcryptjs` is a drop-in, hash-compatible API. Documented here the same way Stage 1 documented its Prisma-translation deviations.
- JWT access tokens: RS256, 15-minute TTL, payload `{ sub, org, role, iat, exp, jti }` exactly per EDD Section 8.1. Refresh tokens: 30-day TTL, single-use, rotated on every refresh, stored as a hash in Redis (EDD Section 8.1).
- API key format: `rc_live_` / `rc_test_` prefix + 32 random bytes as base58 (EDD Section 8.1); stored as bcrypt hash + 12-char `key_prefix` for display/lookup.
- Every resource is org-scoped from this stage forward (concept doc Section 5) — no endpoint in this plan returns or mutates a resource without checking the caller's `org_id` matches.
- A user can never grant an API key more permission than their own role already has (EDD Section 8.2, concept doc Section 6) — enforced server-side, not just documented.
- Secrets never committed to git: JWT keypair lives in `apps/identity-service/keys/*.pem`, generated by a script, git-ignored. `.env.example` gets new placeholder entries, `.env` stays git-ignored (Stage 1 convention).
- Full RBAC enforcement, audit logging, and rate limiting are explicitly **Stage 11** per the PRD roadmap (Section 7, row 11) and the EDD's own risk table (Section 8, "Risks & Assumptions") — this stage builds the `role` claim and a minimal `RolesGuard` for org/member management endpoints (needed for those endpoints to make any sense at all), but does **not** add audit-log writes or rate limiting. Do not scope-creep into Stage 11's work.
- Two documented, deliberate schema extensions beyond the EDD's Section 6.1 tables (added via a new Prisma migration in `packages/db`, additive only — no changes to Stage 1's existing tables/migration): `password_reset_tokens` table (the EDD lists `POST /auth/forgot-password` / `reset-password` endpoints in Section 7.1 but Section 6.1 never defines storage for the reset token — mirrors the existing `email_verification_tokens` table) and `users.deleted_at` (the EDD lists `DELETE /users/me` as "soft delete" in Section 7.2 but Section 6.1's `users` table has no soft-delete column).
- One documented endpoint beyond the EDD's literal Section 7.1 list: `POST /api/v1/auth/select-org`. The EDD's JWT payload embeds a single `org`/`role` pair (Section 8.1), but a user can belong to multiple organizations (concept doc Section 5) — nothing in the EDD's endpoint list re-mints a token for a *different* org once one is chosen. This endpoint is the necessary plumbing to make the spec's own JWT structure work for multi-org users; documented the same way Stage 1 flagged its own justified deviations.
- Node.js >= 22, pnpm 9.11.0, TypeScript 5, ESM (`"type": "module"`) throughout — matches Stage 1.
- **Vitest needs an SWC transform, not its default esbuild transform, for Nest DI to work.** Vite/Vitest's default esbuild-based TS transform does not emit `design:paramtypes` decorator metadata, so any constructor parameter typed only by class (`private readonly x: SomeService`, no `@Inject(...)`) resolves as `undefined` at runtime — Nest can't tell what to inject. Fixed once, in Task 2, by adding `unplugin-swc` + `@swc/core` as dev dependencies, an `.swcrc` with `"transform": { "legacyDecorator": true, "decoratorMetadata": true }`, and `plugins: [swc.vite()]` in both `vitest.config.ts` and `vitest.integration.config.ts`. Every later task's plain-class constructor injection (no explicit `@Inject`) relies on this being in place — do not remove it.
- **Every relative import needs an explicit `.js` extension** (e.g. `from './env.js'`, not `from './env'`) — required by `moduleResolution: NodeNext` (`tsconfig.base.json`), confirmed by the already-committed `packages/config/src/index.ts` (`export * from './env.js';`). Code blocks below that omit this were written before this was rediscovered mid-Task-1 — apply the extension when actually writing each file regardless of what a given snippet shows. Likewise `import Redis from 'ioredis'` does not typecheck under this resolution mode (`ioredis` has no usable default export here) — use the named import `import { Redis } from 'ioredis'` everywhere `ioredis` is imported.
- Do not modify `packages/config`'s existing exports — only extend via a local `env.ts` in `apps/identity-service` that imports and extends `baseEnvSchema`, exactly as Stage 1's plan documented for future services.

- [ ] **Step 5: Create `apps/identity-service/scripts/generate-jwt-keys.cjs`**

```javascript
#!/usr/bin/env node
const { generateKeyPairSync } = require('node:crypto');
const { mkdirSync, writeFileSync, existsSync } = require('node:fs');
const { join } = require('node:path');

const keysDir = join(__dirname, '..', 'keys');
mkdirSync(keysDir, { recursive: true });

const privatePath = join(keysDir, 'private.pem');
const publicPath = join(keysDir, 'public.pem');

if (existsSync(privatePath) && existsSync(publicPath)) {
  console.log('JWT keypair already exists at apps/identity-service/keys/, skipping.');
  process.exit(0);
}

const { privateKey, publicKey } = generateKeyPairSync('rsa', {
  modulusLength: 2048,
  publicKeyEncoding: { type: 'spki', format: 'pem' },
  privateKeyEncoding: { type: 'pkcs8', format: 'pem' },
});

writeFileSync(privatePath, privateKey);
writeFileSync(publicPath, publicKey);
console.log('Generated JWT RS256 keypair at apps/identity-service/keys/.');
```

```typescript
export async function hashPassword(plain: string, rounds: number): Promise<string> {
  return bcrypt.hash(plain, rounds);
}

export async function comparePassword(plain: string, hash: string): Promise<boolean> {
  return bcrypt.compare(plain, hash);
}
```

```typescript
import { JwtService } from '@nestjs/jwt';
import { randomBytes, randomUUID } from 'node:crypto';
import { readFileSync } from 'node:fs';
import { resolve } from 'node:path';
import type Redis from 'ioredis';
import bcrypt from 'bcryptjs';
import { REDIS } from '../redis/redis.module';
import { APP_ENV } from '../app-env.token';
import type { AppEnv } from '../env';

export interface AccessTokenClaims {
  sub: string;
  org: string | null;
  role: string | null;
  jti: string;
  iat: number;
  exp: number;
}

const REFRESH_HASH_ROUNDS = 10;

@Injectable()
export class TokenService {
  private readonly jwt: JwtService;
  private readonly accessTtl: number;
  private readonly refreshTtl: number;

  constructor(
    @Inject(REDIS) private readonly redis: Redis,
    @Inject(APP_ENV) env: AppEnv,
    privateKeyOverride?: string,
    publicKeyOverride?: string,
  ) {
    const privateKey = privateKeyOverride ?? readFileSync(resolve(env.JWT_PRIVATE_KEY_PATH), 'utf-8');
    const publicKey = publicKeyOverride ?? readFileSync(resolve(env.JWT_PUBLIC_KEY_PATH), 'utf-8');
    this.jwt = new JwtService({ privateKey, publicKey, signOptions: { algorithm: 'RS256' } });
    this.accessTtl = env.JWT_ACCESS_TTL_SECONDS;
    this.refreshTtl = env.JWT_REFRESH_TTL_SECONDS;
  }

  async mintAccessToken(payload: { sub: string; org: string | null; role: string | null }): Promise<string> {
    return this.jwt.signAsync(
      { sub: payload.sub, org: payload.org, role: payload.role },
      { expiresIn: this.accessTtl, jwtid: randomUUID() },
    );
  }

  async verifyAccessToken(token: string): Promise<AccessTokenClaims> {
    return this.jwt.verifyAsync<AccessTokenClaims>(token, { algorithms: ['RS256'] });
  }

  async mintRefreshToken(userId: string): Promise<string> {
    const id = randomUUID();
    const secret = randomBytes(32).toString('hex');
    const secretHash = await bcrypt.hash(secret, REFRESH_HASH_ROUNDS);
    await this.redis.set(`refresh:${id}`, JSON.stringify({ userId, secretHash }), 'EX', this.refreshTtl);
    return `${id}.${secret}`;
  }

  async verifyAndRotateRefreshToken(token: string): Promise<{ userId: string; newRefreshToken: string }> {
    const [id, secret] = token.split('.');
    if (!id || !secret) {
      throw new Error('Malformed refresh token');
    }
    const raw = await this.redis.get(`refresh:${id}`);
    if (!raw) {
      throw new Error('Refresh token not found or already used');
    }
    const { userId, secretHash } = JSON.parse(raw) as { userId: string; secretHash: string };
    const valid = await bcrypt.compare(secret, secretHash);
    if (!valid) {
      throw new Error('Refresh token signature mismatch');
    }
    await this.redis.del(`refresh:${id}`);
    const newRefreshToken = await this.mintRefreshToken(userId);
    return { userId, newRefreshToken };
  }

  async revokeRefreshToken(token: string): Promise<void> {
    const [id] = token.split('.');
    if (id) {
      await this.redis.del(`refresh:${id}`);
    }
  }

  async blacklistAccessToken(jti: string, expiresInSeconds: number): Promise<void> {
    if (expiresInSeconds <= 0) {
      return;
    }
    await this.redis.set(`jwt:blacklist:${jti}`, '1', 'EX', expiresInSeconds);
  }

  async isAccessTokenBlacklisted(jti: string): Promise<boolean> {
    const value = await this.redis.get(`jwt:blacklist:${jti}`);
    return value !== null;
  }
}
```

```typescript
import { ConflictException, Inject, Injectable, UnauthorizedException } from '@nestjs/common';
import type { PrismaClient } from '@rivocloud/db';
import { PRISMA } from '../prisma/prisma.module';
import { APP_ENV } from '../app-env.token';
import type { AppEnv } from '../env';
import { TokenService } from './token.service';
import { hashPassword, comparePassword } from './password.util';

export interface AuthTokens {
  accessToken: string;
  refreshToken: string;
}

@Injectable()
export class AuthService {
  constructor(
    @Inject(PRISMA) private readonly db: PrismaClient,
    @Inject(APP_ENV) private readonly env: AppEnv,
    private readonly tokens: TokenService,
  ) {}

  async register(email: string, password: string, name: string) {
    const existing = await this.db.user.findUnique({ where: { email } });
    if (existing) {
      throw new ConflictException('An account with this email already exists');
    }
    const passwordHash = await hashPassword(password, this.env.BCRYPT_SALT_ROUNDS);
    const user = await this.db.user.create({ data: { email, passwordHash, name } });
    return user;
  }

  async login(email: string, password: string): Promise<AuthTokens & { userId: string }> {
    const user = await this.db.user.findUnique({ where: { email } });
    if (!user || !user.passwordHash || user.deletedAt) {
      throw new UnauthorizedException('Invalid email or password');
    }
    const valid = await comparePassword(password, user.passwordHash);
    if (!valid) {
      throw new UnauthorizedException('Invalid email or password');
    }

    const memberships = await this.db.organizationMember.findMany({ where: { userId: user.id } });
    const soleMembership = memberships.length === 1 ? memberships[0] : null;

    const accessToken = await this.tokens.mintAccessToken({
      sub: user.id,
      org: soleMembership?.orgId ?? null,
      role: soleMembership?.role ?? null,
    });
    const refreshToken = await this.tokens.mintRefreshToken(user.id);
    return { accessToken, refreshToken, userId: user.id };
  }

  async refresh(refreshToken: string): Promise<AuthTokens> {
    let rotated: { userId: string; newRefreshToken: string };
    try {
      rotated = await this.tokens.verifyAndRotateRefreshToken(refreshToken);
    } catch {
      throw new UnauthorizedException('Invalid or expired refresh token');
    }
    const user = await this.db.user.findUnique({ where: { id: rotated.userId } });
    if (!user || user.deletedAt) {
      throw new UnauthorizedException('Invalid or expired refresh token');
    }
    const memberships = await this.db.organizationMember.findMany({ where: { userId: user.id } });
    const soleMembership = memberships.length === 1 ? memberships[0] : null;
    const accessToken = await this.tokens.mintAccessToken({
      sub: user.id,
      org: soleMembership?.orgId ?? null,
      role: soleMembership?.role ?? null,
    });
    return { accessToken, refreshToken: rotated.newRefreshToken };
  }

  async logout(accessTokenJti: string, accessTokenExpiresInSeconds: number, refreshToken: string): Promise<void> {
    await this.tokens.blacklistAccessToken(accessTokenJti, accessTokenExpiresInSeconds);
    await this.tokens.revokeRefreshToken(refreshToken);
  }
}
```

```typescript
import { Body, Controller, Post, UnauthorizedException } from '@nestjs/common';
import { AuthService } from './auth.service';
import { TokenService } from './token.service';
import { RegisterDto } from './dto/register.dto';
import { LoginDto } from './dto/login.dto';
import { RefreshDto } from './dto/refresh.dto';
import { LogoutDto } from './dto/logout.dto';

@Controller('api/v1/auth')
export class AuthController {
  constructor(
    private readonly auth: AuthService,
    private readonly tokens: TokenService,
  ) {}

  @Post('register')
  async register(@Body() dto: RegisterDto) {
    const user = await this.auth.register(dto.email, dto.password, dto.name);
    return { id: user.id, email: user.email, name: user.name };
  }

  @Post('login')
  async login(@Body() dto: LoginDto) {
    const { accessToken, refreshToken } = await this.auth.login(dto.email, dto.password);
    return { accessToken, refreshToken };
  }

  @Post('refresh')
  async refreshToken(@Body() dto: RefreshDto) {
    const { accessToken, refreshToken } = await this.auth.refresh(dto.refreshToken);
    return { accessToken, refreshToken };
  }

  @Post('logout')
  async logout(@Body() dto: LogoutDto) {
    let claims;
    try {
      claims = await this.tokens.verifyAccessToken(
        dto.refreshToken.includes('.') ? '' : dto.refreshToken,
      );
    } catch {
      claims = null;
    }
    // Logout is driven by the refresh token alone; the access token, if the
    // client still has one, is optional and best-effort blacklisted below.
    void claims;
    await this.tokens.revokeRefreshToken(dto.refreshToken);
    return { success: true };
  }
}
```

```typescript
import { createHash, randomBytes } from 'node:crypto';

export function generateRawToken(): { raw: string; hash: string } {
  const raw = randomBytes(32).toString('hex');
  const hash = createHash('sha256').update(raw).digest('hex');
  return { raw, hash };
}

export function hashToken(raw: string): string {
  return createHash('sha256').update(raw).digest('hex');
}
```

```typescript
import { Injectable, Logger, OnModuleDestroy } from '@nestjs/common';
import { connect, JSONCodec, type NatsConnection } from 'nats';

@Injectable()
export class EventsService implements OnModuleDestroy {
  private readonly logger = new Logger(EventsService.name);
  private readonly codec = JSONCodec();
  private connectionPromise: Promise<NatsConnection | null> | null = null;

  constructor(private readonly natsUrl: string) {}

  private async getConnection(): Promise<NatsConnection | null> {
    if (!this.connectionPromise) {
      this.connectionPromise = connect({ servers: this.natsUrl }).catch((error) => {
        this.logger.warn(`NATS unavailable, events will be dropped: ${error.message}`);
        return null;
      });
    }
    return this.connectionPromise;
  }

  async publish(subject: string, payload: unknown): Promise<void> {
    const connection = await this.getConnection();
    if (!connection) {
      return;
    }
    connection.publish(subject, this.codec.encode(payload));
  }

  async onModuleDestroy() {
    const connection = await this.getConnection();
    await connection?.close();
  }
}
```

```typescript
    });

  }

    const tokenHash = hashToken(rawToken);
    const record = await this.db.passwordResetToken.findUnique({ where: { tokenHash } });
    if (!record || record.expiresAt < new Date()) {
      throw new UnauthorizedException('Invalid or expired reset token');
    }
    const passwordHash = await hashPassword(newPassword, this.env.BCRYPT_SALT_ROUNDS);
    await this.db.user.update({ where: { id: record.userId }, data: { passwordHash } });
    await this.db.passwordResetToken.delete({ where: { id: record.id } });
  }
```

```typescript
import { connect, JSONCodec, type NatsConnection } from 'nats';

@Injectable()
export class EventsService implements OnModuleDestroy {
  private readonly logger = new Logger(EventsService.name);
  private readonly codec = JSONCodec();
  private connectionPromise: Promise<NatsConnection | null> | null = null;
  private readonly lastPublished = new Map<string, unknown>();

  constructor(private readonly natsUrl: string) {}

  private async getConnection(): Promise<NatsConnection | null> {
    if (!this.connectionPromise) {
      this.connectionPromise = connect({ servers: this.natsUrl }).catch((error) => {
        this.logger.warn(`NATS unavailable, events will be dropped: ${error.message}`);
        return null;
      });
    }
    return this.connectionPromise;
  }

  async publish(subject: string, payload: unknown): Promise<void> {
    this.lastPublished.set(subject, payload);
    const connection = await this.getConnection();
    if (!connection) {
      return;
    }
    connection.publish(subject, this.codec.encode(payload));
  }

  getLastPublished<T>(subject: string): T | undefined {
    return this.lastPublished.get(subject) as T | undefined;
  }

  async onModuleDestroy() {
    const connection = await this.getConnection();
    await connection?.close();
  }
}
```

```typescript
import { CanActivate, ExecutionContext, Injectable, UnauthorizedException } from '@nestjs/common';
import { TokenService } from './token.service';

@Injectable()
export class JwtOnlyGuard implements CanActivate {
  constructor(private readonly tokens: TokenService) {}

  async canActivate(context: ExecutionContext): Promise<boolean> {
    const request = context.switchToHttp().getRequest();
    const header = request.headers['authorization'];
    if (!header?.startsWith('Bearer ')) {
      throw new UnauthorizedException('Missing bearer token');
    }
    const token = header.slice('Bearer '.length);
    let claims;
    try {
      claims = await this.tokens.verifyAccessToken(token);
    } catch {
      throw new UnauthorizedException('Invalid or expired token');
    }
    if (await this.tokens.isAccessTokenBlacklisted(claims.jti)) {
      throw new UnauthorizedException('Token has been revoked');
    }
    request.auth = { userId: claims.sub, orgId: claims.org, role: claims.role };
    return true;
  }
}
```

```typescript
import { ConflictException, ForbiddenException, Inject, Injectable, NotFoundException } from '@nestjs/common';
import type { PrismaClient } from '@rivocloud/db';
import { PRISMA } from '../prisma/prisma.module';
import { EventsService } from '../events/events.service';
import { slugify } from './slug.util';
import type { OrgRole } from './roles';

@Injectable()
export class OrganizationsService {
  constructor(
    @Inject(PRISMA) private readonly db: PrismaClient,
    private readonly events: EventsService,
  ) {}

  async create(ownerId: string, name: string) {
    const baseSlug = slugify(name) || 'org';
    let slug = baseSlug;
    let attempt = 0;
    while (await this.db.organization.findUnique({ where: { slug } })) {
      attempt += 1;
      slug = `${baseSlug}-${attempt}`;
    }

    const org = await this.db.organization.create({
      data: {
        name,
        slug,
        ownerId,
        members: { create: { userId: ownerId, role: 'owner', joinedAt: new Date() } },
      },
    });
    await this.events.publish('org.created', { orgId: org.id, ownerId, slug: org.slug });
    return org;
  }

  async listForUser(userId: string) {
    return this.db.organization.findMany({ where: { members: { some: { userId } } } });
  }

  async getForMember(orgId: string, userId: string) {
    const membership = await this.db.organizationMember.findUnique({
      where: { orgId_userId: { orgId, userId } },
    });
    if (!membership) {
      throw new NotFoundException('Organization not found');
    }
    const org = await this.db.organization.findUniqueOrThrow({ where: { id: orgId } });
    return org;
  }

  async update(orgId: string, data: { name?: string }) {
    return this.db.organization.update({ where: { id: orgId }, data });
  }

  async delete(orgId: string) {
    await this.db.organization.delete({ where: { id: orgId } });
  }

  async listMembers(orgId: string) {
    return this.db.organizationMember.findMany({ where: { orgId }, include: { user: true } });
  }

  async addMember(orgId: string, invitedBy: string, email: string, role: OrgRole) {
    const user = await this.db.user.findUnique({ where: { email } });
    if (!user) {
      throw new NotFoundException('No registered user with that email — they must sign up first');
    }
    const existing = await this.db.organizationMember.findUnique({
      where: { orgId_userId: { orgId, userId: user.id } },
    });
    if (existing) {
      throw new ConflictException('User is already a member of this organization');
    }
    return this.db.organizationMember.create({
      data: { orgId, userId: user.id, role, invitedBy, joinedAt: new Date() },
    });
  }

  async updateMemberRole(orgId: string, targetUserId: string, role: OrgRole) {
    const membership = await this.db.organizationMember.findUnique({
      where: { orgId_userId: { orgId, userId: targetUserId } },
    });
    if (!membership) {
      throw new NotFoundException('Member not found');
    }
    if (membership.role === 'owner') {
      throw new ForbiddenException("The organization's owner role cannot be changed here");
    }
    return this.db.organizationMember.update({
      where: { orgId_userId: { orgId, userId: targetUserId } },
      data: { role },
    });
  }

  async removeMember(orgId: string, targetUserId: string) {
    const membership = await this.db.organizationMember.findUnique({
      where: { orgId_userId: { orgId, userId: targetUserId } },
    });
    if (!membership) {
      throw new NotFoundException('Member not found');
    }
    if (membership.role === 'owner') {
      throw new ForbiddenException('Cannot remove the organization owner');
    }
    await this.db.organizationMember.delete({ where: { orgId_userId: { orgId, userId: targetUserId } } });
  }
}
```

```typescript
import { CanActivate, ExecutionContext, ForbiddenException, Injectable, SetMetadata } from '@nestjs/common';
import { Reflector } from '@nestjs/core';
import type { OrgRole } from './roles';

export const ROLES_KEY = 'roles';
export const Roles = (...roles: OrgRole[]) => SetMetadata(ROLES_KEY, roles);

@Injectable()
export class RolesGuard implements CanActivate {
  constructor(private readonly reflector: Reflector) {}

  canActivate(context: ExecutionContext): boolean {
    const required = this.reflector.get<OrgRole[] | undefined>(ROLES_KEY, context.getHandler());
    if (!required || required.length === 0) {
      return true;
    }
    const request = context.switchToHttp().getRequest();
    const role = request.auth?.role;
    if (!role || !required.includes(role)) {
      throw new ForbiddenException(`Requires one of roles: ${required.join(', ')}`);
    }
    return true;
  }
}
```

```typescript
import { BadRequestException, ForbiddenException, Inject, Injectable, NotFoundException } from '@nestjs/common';
import type { PrismaClient } from '@rivocloud/db';
import { PRISMA } from '../prisma/prisma.module';
import { APP_ENV } from '../app-env.token';
import type { AppEnv } from '../env';
import { hashPassword, comparePassword } from '../auth/password.util';
import { generateApiKey } from './api-key.util';
import { scopesAllowedForRole, isOrgRole, type ApiKeyScope } from '../organizations/roles';

@Injectable()
export class ApiKeysService {
  constructor(
    @Inject(PRISMA) private readonly db: PrismaClient,
    @Inject(APP_ENV) private readonly env: AppEnv,
  ) {}

  private async assertScopesAllowedForCaller(orgId: string, userId: string, requested: ApiKeyScope[]) {
    const membership = await this.db.organizationMember.findUnique({
      where: { orgId_userId: { orgId, userId } },
    });
    if (!membership || !isOrgRole(membership.role)) {
      throw new ForbiddenException('Not a member of this organization');
    }
    const allowed = new Set(scopesAllowedForRole(membership.role));
    const disallowed = requested.filter((scope) => !allowed.has(scope));
    if (disallowed.length > 0) {
      throw new ForbiddenException(
        `Your role (${membership.role}) cannot grant scopes: ${disallowed.join(', ')}`,
      );
    }
  }

  async create(orgId: string, userId: string, name: string, permissions: ApiKeyScope[], testMode: boolean) {
    if (permissions.length === 0) {
      throw new BadRequestException('At least one permission scope is required');
    }
    await this.assertScopesAllowedForCaller(orgId, userId, permissions);

    const { raw, prefix } = generateApiKey(testMode);
    const keyHash = await hashPassword(raw, this.env.BCRYPT_SALT_ROUNDS);
    const apiKey = await this.db.apiKey.create({
      data: { orgId, userId, name, keyHash, keyPrefix: prefix, permissions },
    });
    return { id: apiKey.id, name: apiKey.name, keyPrefix: apiKey.keyPrefix, permissions, rawKey: raw };
  }

  async list(orgId: string) {
    const keys = await this.db.apiKey.findMany({ where: { orgId, revokedAt: null } });
    return keys.map((key) => ({
      id: key.id,
      name: key.name,
      keyPrefix: key.keyPrefix,
      permissions: key.permissions,
      lastUsedAt: key.lastUsedAt,
      expiresAt: key.expiresAt,
    }));
  }

  async update(orgId: string, userId: string, keyId: string, data: { name?: string; permissions?: ApiKeyScope[] }) {
    const key = await this.db.apiKey.findUnique({ where: { id: keyId } });
    if (!key || key.orgId !== orgId || key.revokedAt) {
      throw new NotFoundException('API key not found');
    }
    if (data.permissions) {
      await this.assertScopesAllowedForCaller(orgId, userId, data.permissions);
    }
    return this.db.apiKey.update({ where: { id: keyId }, data });
  }

  async revoke(orgId: string, keyId: string) {
    const key = await this.db.apiKey.findUnique({ where: { id: keyId } });
    if (!key || key.orgId !== orgId || key.revokedAt) {
      throw new NotFoundException('API key not found');
    }
    await this.db.apiKey.update({ where: { id: keyId }, data: { revokedAt: new Date() } });
  }

  async verifyRawKey(raw: string) {
    const prefix = raw.slice(0, 12);
    const candidates = await this.db.apiKey.findMany({ where: { keyPrefix: prefix, revokedAt: null } });
    for (const candidate of candidates) {
      if (candidate.expiresAt && candidate.expiresAt < new Date()) {
        continue;
      }
      if (await comparePassword(raw, candidate.keyHash)) {
        await this.db.apiKey.update({ where: { id: candidate.id }, data: { lastUsedAt: new Date() } });
        return candidate;
      }
    }
    return null;
  }
}
```

```typescript
import { CanActivate, ExecutionContext, Inject, Injectable, UnauthorizedException } from '@nestjs/common';
import { TokenService } from './token.service';
import { ApiKeysService } from '../api-keys/api-keys.service';

@Injectable()
export class AuthGuard implements CanActivate {
  constructor(
    private readonly tokens: TokenService,
    @Inject(ApiKeysService) private readonly apiKeys: ApiKeysService,
  ) {}

  async canActivate(context: ExecutionContext): Promise<boolean> {
    const request = context.switchToHttp().getRequest();
    const apiKeyHeader = request.headers['x-api-key'] as string | undefined;
    const authHeader = request.headers['authorization'] as string | undefined;

    if (apiKeyHeader?.startsWith('rc_')) {
      const key = await this.apiKeys.verifyRawKey(apiKeyHeader);
      if (!key) {
        throw new UnauthorizedException('Invalid API key');
      }
      request.auth = {
        type: 'api_key',
        userId: key.userId,
        orgId: key.orgId,
        role: null,
        apiKeyId: key.id,
        permissions: key.permissions as string[],
      };
      return true;
    }

    if (!authHeader?.startsWith('Bearer ')) {
      throw new UnauthorizedException('Missing Authorization bearer token or X-API-Key header');
    }
    const token = authHeader.slice('Bearer '.length);
    let claims;
    try {
      claims = await this.tokens.verifyAccessToken(token);
    } catch {
      throw new UnauthorizedException('Invalid or expired token');
    }
    if (await this.tokens.isAccessTokenBlacklisted(claims.jti)) {
      throw new UnauthorizedException('Token has been revoked');
    }
    request.auth = { type: 'jwt', userId: claims.sub, orgId: claims.org, role: claims.role };
    return true;
  }
}
```
